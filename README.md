# 🐉 Dragon Ball Power-Up Diner

An interactive web game where you feed iconic Dragon Ball characters to increase their power levels with satisfying animations and visual effects!

## 🎮 About

This project is an educational exercise in collaborative development, focusing on:
- Git/GitHub workflow and teamwork
- React component architecture
- Browser APIs (localStorage)
- CSS animations and visual effects
- Responsive design

## ✨ Features

- **Character System**: Feed multiple Dragon Ball characters
- **Power-Up Mechanics**: Watch power levels increase with animated effects
- **Food Inventory**: Manage and purchase different food items
- **Persistence**: Progress automatically saved to browser storage
- **Leaderboard**: Track your strongest characters
- **Responsive**: Works on desktop and mobile devices

## 🚀 Quick Start

### Prerequisites
- Node.js 18.x or higher
- npm 9.x or higher
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/dragon-ball-power-up-diner.git
cd dragon-ball-power-up-diner
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`
